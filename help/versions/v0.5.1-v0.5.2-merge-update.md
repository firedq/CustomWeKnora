### 修复
- **LLM 超时**：为非流式/流式调用添加超时保护，防止 worker 被 hung 请求永久阻塞；兜底超时仅在上层无 deadline 时生效
- **Anthropic 网关**：修复流式传输支持

- **Ollama**：适配 ToolCallFunctionArguments struct API
- **Embedding**：修复 OpenAIEmbedder 连接失败时 nil deref → SIGSEGV
- **Session**：ErrSessionNotFound 映射为 404；按用户限定 session 访问
- **知识库**：ErrKnowledgeBaseNotFound 映射为 404
- **Migration**：确保 pg_trgm 在 trigram index 之前创建
- **Agent**：replay attachments in multi-turn history；放宽 rerank model 要求；修复图谱配置报告
- **飞书**：容忍 wiki node 部分列表失败
- **多模态**：provider:// 图片读取失败时不阻塞处理
- **安全**：camelCase secret fields 在请求日志中脱敏；禁止 `<style>` 标签
- **存储**：合并 tos/s3/oss/ks3 租户配置；全局 file service 兜底
- **IM**：clamp reconnect backoff 防止 int64 溢出 → busy loop
- **OIDC**：修复 auth login
- **FAQ 搜索**：修正 PostgreSQL cast 优先级
- **SearXNG**：提供硬编码默认 secret 实现零配置启动
